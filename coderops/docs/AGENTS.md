# Agents

Canonical agent definitions live in `coderops/agents` and are copied to the repository-root `.github/agents` adapter surface.

## Implemented agents

- `coderops-governor`
- `coderops-platform-operator`
- `coderops-template-engineer`
- `coderops-workspace-operator`
- `coderops-ai-operator`
- `coderops-security-auditor`

## Design

The Governor coordinates; the other agents perform domain inspection and safe remediation planning.
